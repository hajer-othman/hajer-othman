## 📌 Selected projects

### 🛍️ [Customer Support Assistant](https://github.com/hajer-othman/customer-support-assistant) · work in progress

A bilingual (French/English) support assistant for a fictional clothing and shoe shop. It answers from policy documents with sources (RAG), looks up orders through tools, creates returns only after an explicit confirmation, and escalates everything else to a human advisor.

- **Safety by design:** the agent can only ask; tools hold the business rules and the customer identity filter, and are the only code that touches the database.
- **Evaluation first:** a 100-question French/English test set (including questions the documents do not cover) built before the RAG itself.
- **Stack:** Python · FastAPI · PostgreSQL + pgvector (Supabase) · SQLAlchemy · Alembic · LangGraph · Langfuse · DeepEval · Docker · GitHub Actions
